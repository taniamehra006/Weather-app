# Weather App 🌦️

A simple Python weather application that fetches live weather data using the OpenWeather API.

## Features

- Search weather by city
- Temperature in Celsius
- Feels Like temperature
- Humidity
- Weather description
- Wind speed
- Invalid city handling

## Technologies Used

- Python
- Requests
- OpenWeather API

## Installation

```bash
pip install requests
```

## Run

```bash
python main.py
```
